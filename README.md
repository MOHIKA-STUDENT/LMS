# 📚 English Tutors Academy - Enterprise LMS (MNC Production Architecture)

An MNC-grade, high-performance, offline-first Learning Management System (LMS) built with **Next.js 14**, **Clerk Auth**, **Neon PostgreSQL**, **Prisma ORM**, **Cloudinary CDN**, **Google Gemini AI**, and **Dexie.js (IndexedDB PWA)**.

---

## ✨ Enterprise Features

- 🔐 **Zero-Rate-Limit Clerk Auth**: Google 1-Tap OAuth, instant session management, and role metadata (`TEACHER` vs `STUDENT`).
- 🛡️ **Teacher Passcode Protection**: Teacher signup protected with security passcode (`TEACHER2026`).
- 🎯 **Batch / Group Engine**: Filter quizzes, homework assignments, schedule timelines, and study materials strictly by student batch.
- 🗄️ **Neon Serverless PostgreSQL + Prisma ORM**: Zero SQL circular recursion errors, type-safe data modeling, and relational cascades.
- ☁️ **Cloudinary CDN Storage**: 25GB free CDN storage with a 5MB client-side asset shield and image compression.
- 🤖 **Gemini AI Quiz Generator**: Server-side 5-question CEFR-aligned English quiz creation (A1 to C2) based on custom topics.
- ✍️ **AI Homework Proofreader**: Instant grammar, spelling, and structural feedback reports generated by Gemini AI.
- 📴 **Offline-First PWA & Auto-Sync**: Dexie.js IndexedDB queues offline quiz and homework submissions and reconciles automatically when back online.
- 🏆 **Gamified Leaderboards**: Real-time point tracking and global vs batch rank toggles.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 14 (TypeScript, App Router, Server Actions)
- **Authentication**: Clerk Auth (`@clerk/nextjs`)
- **Database & ORM**: Neon PostgreSQL & Prisma ORM (`@prisma/client`)
- **CDN File Storage**: Cloudinary SDK (`cloudinary`, `next-cloudinary`)
- **AI Tutor Engine**: Google Gemini API (`@google/genai`)
- **Offline Storage**: Dexie.js (IndexedDB)
- **Styling & UI**: Tailwind CSS, Lucide Icons, Glassmorphism UI
- **Alerts**: Sonner

## 🚀 Quick Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MOHIKA-STUDENT/LMS.git
   cd LMS
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env.local` and add your Clerk, Neon, Cloudinary, and Gemini keys:
   ```bash
   cp .env.example .env.local
   ```

4. **Push Database Schema**:
   ```bash
   npx prisma db push
   ```

5. **Run Development Server**:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🔒 Security & Privacy

- Secret environment files (`.env.local`) and local developer guides (`PROJECT_EXPLANATION.md`) are strictly gitignored.
- AI prompts and Cloudinary API secrets execute exclusively within Next.js Server Actions.
- Role authorization is guarded at the middleware layer using `clerkMiddleware()`.
